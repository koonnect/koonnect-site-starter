# Marketing Site — UI Kit

Pixel-oriented recreation of the Koonnect dark-mode marketing site (Koonnect '25 layout).

## Components
- `Header.jsx` — sticky dark header + mega menu (Soluções / Plataforma)
- `Hero.jsx` — full-bleed image hero with glass search bar
- `SolutionsGrid.jsx` — 4-pillar outlined cards (Criação / Marketing / Otimização / Expansão)
- `Banners.jsx` — TransformBanner (twin-rail image panels) + DemoCTA panel
- `Sections.jsx` — Clients, News, Press, Newsletter
- `Footer.jsx` — 5-column dark footer with brand column
- `ContactPage.jsx` — full contact route with form

## Notes
- Placeholder icons (lucide-style line SVGs) are used inside the Solutions pillar cards. Real Figma icons were not present as flattened SVGs — flag this for a swap once icon source is available.
- Press/news thumbnails are copied from the Figma; client logos are the monochrome wordmarks (filtered to white).
- The gold→blue vertical gradient and arrow-badge pattern are applied to signature spots (CTA arrow, headlines).

## Run
Open `index.html`. Click "Agendar Demo" in the header or the CTA panel to navigate to the Contact page.
